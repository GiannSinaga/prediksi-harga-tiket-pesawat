# prediksi-harga-tiket-pesawat
 Projek untuk memprediksi harga tiket pesawat dengan menerapkan algoritma machine Learning.
 
 Dalam kasus ini, terdapat 2 model yaitu  Linear Regression dan Random Forest Regression sebagai perbandingan untuk dipilih berdasarkan akurasi yang lebih tinggi.

 
 Bahasa pemrograman : Python 
 Library : Matplotlib, Scikit-learn
 Tools : Google Big Query, Google Colab

 
Dataset's Source : https://www.kaggle.com/datasets/leomauro/argodatathon2019?resource=download
